# MediLink — Definition of Done

An issue can only be marked Done when:
- All acceptance criteria are satisfied.
- Relevant changes or reviewable artifacts are linked.
- Tests or simulation checks have been completed.
- Another team member reviewed the work.
- Review feedback has been addressed.
- Verification results are recorded.
- Documentation is updated where applicable.
- Privacy and security considerations are checked.
- No unresolved critical problems remain.
- The issue is moved to Done on the Project Board.

WIP Policy: Maximum two issues in In Progress.

Engineering Management Policy:
The Engineering Manager coordinates and coaches;
developers remain responsible for their assigned work.
